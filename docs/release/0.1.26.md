# 天猫运营工作台 v0.1.26

## 工作台桌面

- 启动后首先进入“天猫运营工作台”桌面，不再直接占用整个窗口显示 SKU 控制台。
- 提供 `SKU ID 重建`、`任务中心`、`浏览器会话`三个可执行快捷方式，支持双击和键盘 Enter。
- SKU 重建以单实例内部窗口运行，支持拖动、调整大小、最小化、最大化、还原和关闭。
- 底部任务栏支持显示桌面和恢复运行应用，并持续显示 Worker、店铺会话、运行任务和待复核状态。
- 最小化或关闭内部窗口只改变可见性，不会卸载 SKU 模块或停止 Worker 后台任务；导入草稿和当前模块状态在本次桌面会话中保留。

## SKU 应用边界

- SKU ID 重建仍只执行天猫商品快照、临时唯一规格提交、新 SKU ID 回读、原业务字段恢复提交和最终严格回读。
- 不调用 OMS，不查询或补全外部商品资料/条码，不执行国补提交。
- 同一批次最多两路不同商品流水线；所有 `/tmall/submit.htm` 写请求保持串行。
- 150 秒最终回读、商品级未确认写入锁、未知结果人工复核和禁止自动重试规则均未改变。
