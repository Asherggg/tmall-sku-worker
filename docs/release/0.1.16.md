# Tmall SKU Worker v0.1.16

## 变更

- 继承 v0.1.15 的延迟收敛回读窗口。
- 兼容销售属性预检返回完整笛卡尔积、商品只启用其中部分组合的 SKU 明细页。
- 仅忽略同时满足 `skuId=0`、无 `skuParam_p-*`、无商家编码和条码的额外占位组合。
- 额外组合只要携带 SKU 身份或明细参数，仍然停止写入并进入人工复核。
