# Tmall SKU Worker v0.1.18

## 变更

- 最终提交后的服务端回读由固定次数改为 150 秒截止时间，按 2 秒间隔只读 `GET /tmall/publish.htm`；截止点再执行一次新鲜 GET，仍不一致才进入人工复核，不重复提交。
- 回读审计增加 `deadlineMs` 和 `deadlineReadback`，可区分截止点最终回读与普通轮询。
- “检查全部登录”同时验证同一专属 Edge Profile 中的淘宝、OMS 和国补页面。OMS 仅检查页面、内存 token 和平台商品界面；国补仅检查目标路径与商品管理界面，不调用 OMS 查询/禁用或国补提交接口。
- “打开 OMS 标签页”和“打开国补标签页”在现有会话已登录时立即显示“会话已验证”，不再无条件重置为“未验证”。

## 线上证据

- `1061776009736` 在 v0.1.17 最终提交后约 109 秒完成收敛；新鲜回读确认 9 个 SKU、Doris 69 码、规格、价格、商家编码和销售属性一致。
- `683733874244` 在 v0.1.17 最终提交后约 79 秒完成收敛；新鲜回读确认 6 个 SKU 及全部 Doris 69 码一致。
- 两个样本均超过旧版约 50 秒窗口，但落在新的 150 秒截止时间内。
- 当前真实会话只读验证返回：淘宝有效、OMS 有效、国补有效（3/3）。

## 安全边界

- 最终回读延长只增加只读 GET，不增加或重试任何提交。
- 登录验证不保存 OMS token、Cookie 或页面正文，只保存布尔状态。
- 风控、验证码、登录过期或截止时间后仍不一致，继续进入人工处理。
