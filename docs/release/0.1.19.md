# Tmall SKU Worker v0.1.19

## 变更

- 增加应用数据目录运行时配置文件：`runtime-config.json`。Tauri 显式把配置路径传给 Worker，不再依赖 Windows Explorer 启动时继承的旧环境变量。
- 支持远程商品资料服务配置：
  - `INVENTORY_API_BASE_URL`
  - `INVENTORY_API_PATH`
  - `INVENTORY_API_TOKEN`
  - `INVENTORY_API_ALLOW_INSECURE_HTTP`
  - `TMALL_SUBSIDY_ENABLED`
- 内网 HTTP 远程资料接口必须显式设置 `INVENTORY_API_ALLOW_INSECURE_HTTP=true`；Token 只保存在用户应用数据目录，不写入源码、任务状态或审计导出。
- 保留 v0.1.18 的 150 秒最终回读截止时间、截止点最终新鲜 GET，以及淘宝/OMS/国补三页面只读登录验证。

## 当前配置

应用数据文件位置：

```text
%APPDATA%\com.local.tmall-sku-worker\worker\runtime-config.json
```

配置示例结构（不要把真实 Token 提交到仓库）：

```json
{
  "INVENTORY_API_BASE_URL": "http://10.21.16.213:9031",
  "INVENTORY_API_PATH": "/v1/materials/lookup",
  "INVENTORY_API_TOKEN": "<runtime-token>",
  "INVENTORY_API_ALLOW_INSECURE_HTTP": "true",
  "TMALL_SUBSIDY_ENABLED": "true"
}
```
