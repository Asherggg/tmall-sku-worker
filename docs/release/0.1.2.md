# Tmall SKU Worker v0.1.2 发布说明

## 交付内容

- Windows Tauri 2 桌面程序，前端为 Vue 3 + TypeScript，Worker 为 Node.js。
- NSIS 安装包支持在安装向导中选择自定义安装目录，默认按当前用户安装，不要求管理员权限。
- 安装包内置 Node runtime、`playwright` 和 `playwright-core`，安装后不依赖系统 `PATH` 中的 Node。
- Worker 脚本和 `browser-url.mjs` 一并打包；运行时继续使用系统 Edge 的 CDP，避免额外下载 Chromium。
- 批量输入支持“每行一个商品 ID”，同时兼容原有带 `itemId` 表头的 CSV。

## 安装与启动

1. 双击 `Tmall SKU Worker_0.1.2_x64-setup.exe`。
2. 在安装向导的目录页面选择目标目录并完成安装。
3. 启动应用后，点击登录并在应用专属 Edge 窗口中人工完成淘宝/天猫验证。
4. 回到控制台执行登录态检查；检查通过后才会连接同一浏览器的 CDP。

Windows 仍需要已安装 Microsoft Edge 和 WebView2。当前版本默认是 `demo` 模式，线上商品写入必须有已审核的适配器契约和显式确认；验证码、滑块或风控不会由程序自动操作。

## 构建复现

```powershell
npm install
npm test
npm run build
npm run prepare:runtime
$env:CARGO = "$env:USERPROFILE\\.rustup\\toolchains\\stable-x86_64-pc-windows-msvc\\bin\\cargo.exe"
npm run tauri:build -- --bundles nsis
```

产物目录：`src-tauri/target/release/bundle/nsis/`。

## 已知边界

- MSI 需要 WiX 工具链；本次交付以 NSIS 安装包为主。
- 通用线上 Tmall 写入适配器仍 fail-closed，演练成功不代表真实商品已修改。
- 应用数据和 Edge 专属 Profile 放在用户应用数据目录，不跟随安装目录复制，也不会写入 Git 仓库。
