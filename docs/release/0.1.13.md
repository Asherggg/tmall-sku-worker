# Tmall SKU Worker v0.1.13

## 变更内容

- 最终回读一致性校验不再比较 `skuStock`。
- 天猫库存系统在重建期间产生的实时库存变化不再把任务转为“人工复核”。
- SKU 数量、新 SKU ID、规格、价格、商家编码、条码、图片及其他业务字段仍然严格校验。
- 成功时间线明确提示“库存采用平台实时值”。

- 单元测试覆盖库存变化时任务成功，以及其他业务字段变化时仍然失败。

- `npm run prepare:runtime`
