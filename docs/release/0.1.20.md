# Tmall SKU Worker v0.1.20

## 变更

- 国补适配器兼容当前页面流程：选择“手动输入商品 ID” -> 输入 `textarea#itemId` -> 下一步 -> 下载模板 -> 填充并上传 XLSX -> 提交。
- 保留旧版“商品 ID + 替换 SKU ID”流程作为兼容分支。
- 上传完成必须检测页面的完成状态后才允许进入提交确认；模板匹配不到全部旧/新 SKU、H/I/O/P/Q 未完整填充或上传未完成时停止。
- 修复捆绑运行时的 ExcelJS 依赖冲突，确保真实国补 XLSX 模板可以在安装包内读取。运行时优先使用 ExcelJS 所需的 `readable-stream` 3.x。
- 保留运行时配置文件、150 秒最终回读和三页面登录验证。
