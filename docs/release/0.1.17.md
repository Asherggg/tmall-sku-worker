# Tmall SKU Worker v0.1.17

## 变更

- 在线商品任务在规格重建前通过同一专属 Edge Profile 的认证上下文调用 OMS：使用平台商品数字 ID 查询，调用 `/base/platformGoods/enable` 切换启用状态为禁用，并再次查询确认全部记录为禁用。
- SKU 快照中缺少 69 码时，按商家编码/料号查询 Doris `guanyuan_back.ecommerce_sales_inventory_daily_report`，补全 `barcode`；同一料号对应多条不一致记录、料号不存在、品名/规格缺失或条码无效时停止并进入人工复核。
- 增加国补模板处理：下载 XLSX 后按旧 SKU/新 SKU 映射填充 H、I、O、P、Q 列，再通过页面上传和提交；模板行缺失或提交没有明确成功提示时不报告成功。
- OMS、SKU 重建和国补提交统一纳入外部写入锁；未知响应不自动重试。
- Worker 增加 `/inventory/health`、`/inventory/lookup`，查询接口只接受料号列表，不接受任意 SQL。
- Tmall SKU 适配器兼容 `newColorSelect` 页面当前的自定义颜色 POST 校验协议、单横线/双横线两种预检组合键，以及可见销售属性与镜像 `skuParam_p-*` 字段同步；最终回读窗口覆盖该类商品较慢的平台一致性收敛。

## 配置

线上流程需要同时满足：

```text
TMALL_LIVE_ENABLED=true
TMALL_LIVE_CONTRACT=tmall-publish-v2
TMALL_SUBSIDY_ENABLED=true
```

Doris 二选一：

```text
# 推荐：本机回环查询服务
DORIS_QUERY_URL=http://127.0.0.1:<port>/query

# 或直接使用 Doris MySQL 协议
DORIS_MYSQL_HOST=<fe-host>
DORIS_MYSQL_PORT=9030
DORIS_MYSQL_USER=<user>
DORIS_MYSQL_PASSWORD=<password>
```

查询服务接收 JSON `{ database, table, materialNos, sql }`，返回 `{ data: [...] }` 或 `{ rows: [...] }`。Worker 只绑定 `127.0.0.1`，不会把数据库凭据写入任务状态或审计记录。

国补页面的输入控件如果因店铺页面版本不同无法按默认占位符定位，可通过 `TMALL_SUBSIDY_SELECTORS` 提供 JSON 选择器覆盖；不要把账号、密码、Cookie 或 Token 写入该配置文件或仓库。

## 登录与执行

1. 在“浏览器登录”页面打开专属 Edge，人工完成淘宝/OMS 登录和安全验证。
2. 可通过“打开 OMS 标签页”和“打开国补标签页”确认两个站点在同一 Profile 中可用；Worker 不填写账号密码，也不操作验证码。
3. 创建并启动线上批次后，Worker 按商品串行执行：OMS 禁用 -> Doris 资料解析 -> Tmall SKU 两阶段重建 -> 国补模板上传提交。
4. 任一写入后的响应未知、回读不一致或模板无法匹配，都必须人工核对后才能解除任务锁。
