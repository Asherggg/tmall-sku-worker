# 天猫运营工作台 v0.1.28

## 发布范围

v0.1.28 修复 Windows 安装/升级时旧 Worker 锁定 bundled `runtime\\node.exe` 导致的 `Error opening file for writing`。修复分为两层：

- Tauri host 将 bundled Node Worker 放入 `JOB_OBJECT_LIMIT_KILL_ON_JOB_CLOSE | JOB_OBJECT_LIMIT_SILENT_BREAKAWAY_OK` Windows Job Object。宿主正常退出或异常关闭时，Worker 不会继续作为孤立进程持有运行时文件；Worker 后续启动的专属 Edge 自动脱离 Job 并保持运行。
- NSIS 增加 `NSIS_HOOK_PREINSTALL` 和 `NSIS_HOOK_PREUNINSTALL`。安装/卸载前通过完整路径匹配 `$INSTDIR\\runtime\\node.exe`，只结束目标安装目录的 bundled Node 进程，再执行文件复制或删除。

SKU ID 重建、新增花型、专属 Edge Profile、确认闸门、串行写锁和严格回读契约没有改变。技术包身份继续为 `Tmall SKU Worker`，界面名称为“天猫运营工作台”。
