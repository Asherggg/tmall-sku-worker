# Tmall SKU Worker v0.1.14

## 变更

- 按服务端发布页模型识别 `standard_sku` 与 `sku_detail` 两类 SKU 结构，不再按商品 ID 硬编码。
- 保留并参与回读比对旧详情页要求的 `skuParam_p-*` 字段，避免 `CHK_SKU_PARAM_REQUIRED_ERROR`。
- 支持多个 SKU 共用同一销售属性组合；预检响应可以按组合返回一行并安全映射到 SKU 明细。
- 支持预检响应为数组、对象映射和嵌套行集合的页面变体。
- 按天猫页面实际行为执行自定义销售属性异步 GET 校验：`keyword=<文本>&pid=<属性 ID>`；校验失败时写入请求不会发出。
- 增加页面结构摘要到任务状态，便于区分标准 SKU、SKU 明细和自定义属性校验路径。

## 安全边界

- 仍然是两阶段提交：临时唯一规格 -> 回读新 SKU -> 恢复原规格 -> 回读验证。
- 未知响应、组合缺失、明细无法映射和异步校验失败继续进入人工复核，不自动重试。
- 兼容分支只使用当前登录页同源接口，不读取或输出 Cookie、Token 或完整请求体。
