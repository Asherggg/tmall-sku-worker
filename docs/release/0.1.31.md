# 天猫运营工作台 v0.1.31

发布日期：2026-09-23

## 发布内容

v0.1.31 修复 Worker 重启后的任务队列恢复问题。持久化状态中的 `queued` 或执行阶段任务不能被当作仍由内存调度器持有；Worker 重启时会将这些任务显式转为 `needs_manual_review`，保留人工确认门槛，不自动重跑任何可能已经发出的线上写入。

- 已发出天猫写入的任务保留商品级未确认写入锁，必须先进行权威服务端核对。
- 未发出写入的中断任务不会自动继续，可按现有任务级重试或删除流程处理。
- 批次状态会根据恢复后的任务状态重新计算，避免 UI 显示无法操作的“活动中”任务。
- 人工删除已发出写入的任务仍要求输入 `确认已人工核对`，并写入 `TASK_MANUALLY_RESOLVED_AND_DELETED` 审计记录。
- 专属 Edge、CDP 端口和 Profile 生命周期保持不变。
