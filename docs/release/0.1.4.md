# Tmall SKU Worker v0.1.4

## 版本定位

v0.1.4 延续 `tmall-publish-v1` 两阶段线上重建，并修复 Windows 安装版启动时显示空白终端窗口的问题。发布版主程序使用 Windows GUI 子系统，Worker 仍通过隐藏进程在后台运行。

## 主要变更

- 发布版启动不再创建 CMD/终端窗口。
- 提交后优先使用同源发布页 bootstrap 快速回读；解析或严格映射失败时自动回退完整页面导航。
- 回读审计记录策略、HTTP 状态、耗时和回退错误码。
- 线上写入确认、完整快照、两阶段恢复、商品级锁和最终字段校验保持不变。
