# Tmall SKU Worker v0.1.10

## 变更内容

- “人工复核”且已经进入线上写入阶段的任务现在可以在人工核对后删除。
- 删除前必须输入确认词：`确认已人工核对`。
- 确认弹窗明确说明：删除只解除本地任务和商品锁，不会撤销天猫已经发生的变更。
- 删除后保留审计事件 `TASK_MANUALLY_RESOLVED_AND_DELETED`。
- 正在执行中的任务仍然不能删除。

## 操作步骤

1. 先在天猫后台核对该商品当前的规格、价格、库存、商家编码、条码和 SKU ID。
2. 在任务队列点击该人工复核任务的垃圾桶按钮。
3. 输入 `确认已人工核对`。
4. 点击“解除锁定并删除”。

删除后，同一个商品可以重新创建任务。该操作不会回滚天猫商品。
