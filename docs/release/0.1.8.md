# Tmall SKU Worker v0.1.8

## 修复内容

- 修正桌面 UI 的 Worker 版本校验：安装版 Worker `0.1.8` 不再被误报为旧版本。
- 修正旧版本提示文案，提示用户应重新打开当前 `0.1.8`。
- 登录窗口默认打开淘宝卖家工作台：`https://myseller.taobao.com/home.htm/QnworkbenchHome/`。
- 保留 `TMALL_LOGIN_URL` 环境变量覆盖能力。
- 登录后仍通过同一专属 Edge Profile 访问发布页并执行纯 HTTP 接口流程。

## 升级

先退出旧版主程序，再运行 `Tmall SKU Worker_0.1.8_x64-setup.exe`。安装会保留专属 Edge Profile 和任务历史。

## 验证

- `/health` 应返回 `workerVersion=0.1.8`。
- UI 不再把当前 `0.1.8` Worker 显示为旧版。
- 点击“打开登录窗口”后默认进入淘宝卖家工作台，而不是 `error.taobao.com`。
