# Tmall SKU Worker v0.1.6

## 版本定位

v0.1.6 修复 NSIS 安装版无法自动定位 Worker 资源、导致主界面打开但后台 Worker 未启动的问题，并保留无 CMD 窗口和快速回读能力。

## 主要变更

- 发布版使用 Windows GUI 子系统，不创建控制台窗口。
- Tauri host 优先从安装程序所在目录解析 `worker/server.mjs` 与 `runtime/node.exe`，再回退 Tauri 资源目录。
- 快速服务端回读、完整页面回退、两阶段线上重建和人工复核规则保持不变。

- `npm test`：37/37 通过。

- `cargo check --manifest-path src-tauri/Cargo.toml`：通过。
