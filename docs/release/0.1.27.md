# 天猫运营工作台 v0.1.27

发布日期：2026-09-20

## 发布内容

- 新增独立 `新增花型` 工作台应用，支持 `.xlsx` 选择/拖放、八列严格校验、按商品分组摘要、源行预览、独立线上确认、任务队列和详情时间线。
- 实际样表 `加花型测试-9.18.xlsx` 解析为 8 个商品、23 条明确 `规格 + 颜色分类` 组合；备注不会删除行，也不会生成 Excel 未列出的笛卡尔积组合。
- 保留线上全部原 SKU 和原 SKU ID。已有组合只读核对价格、商家编码和条码；全部匹配时零 POST 完成，有缺少组合时每个商品最多一次 `/tmall/submit.htm`。
- 新组合必须提供商家编码；规格/颜色属性、值、自定义容量和继承模板必须唯一可判定。组合、商家编码、条码或线上业务字段冲突都在写入前阻断。
- 最终回读严格确认原 SKU ID/业务字段保持、新组合唯一存在并获得新 SKU ID；`skuStock` 继续由平台库存系统管理，不参与阻断。
- 工作台扩展为四个桌面快捷方式和两个持久应用实例。关闭、最小化、任务栏切换不会卸载应用，也不会丢失 SKU 草稿或 Excel 预览。
- 保留最多两路不同商品流水线、全局串行 Tmall 写锁、150 秒回读截止、截止点新鲜 GET、未知结果人工复核和已发出写入禁止自动重试。

## Excel 契约

必填表头：`商品ID、规格、颜色分类、价格、数量、商家编码、条形码、备注`。

- 读取首个非空工作表，单批最多 500 行。
- 标识字段按字符串保留，错误包含 Excel 源行号。
- 业务单元格公式、缺失表头、重复组合、重复商家编码和非法数值会阻断批次。
- `原花型不增加新规格`只表示不扩展未列出的组合；该行本身仍是目标组合。
