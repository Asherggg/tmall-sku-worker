# Tmall SKU Worker v0.1.23

## 固定工作流

- 商品资料服务固定为 `http://10.21.16.213:9031/v1/materials/lookup`，不再读取用户侧地址、路径或内网 HTTP 开关。
- 国补流程固定开启，不再读取用户侧国补开关。
- 访问凭据随发布安装资源提供。构建脚本从 `TMALL_RELEASE_RUNTIME_CONFIG` 指定的受控文件读取；未指定时使用当前发布机应用数据目录的配置。生成文件位于被 Git 忽略的 `src-tauri/resources/`。
- Tauri host 从安装资源读取凭据并只注入 Worker 子进程环境。凭据不进入 Git 源码、桌面 UI、任务状态或审计导出。
- 桌面 UI 移除“流程配置”入口。用户安装后只需完成淘宝卖家中心、OMS 和国补三个站点登录。
- 构建时缺少访问凭据会直接失败，不生成半配置安装包。

## 回归覆盖

- 空的用户运行时配置只影响源码/测试 Worker；安装版由 Tauri 注入固定凭据。
- 旧 `runtime-config.json` 中的地址、路径、HTTP 开关或国补开关不能覆盖安装版固定值。
- 固定接口仍执行认证、响应结构、料号唯一性、69 码、品名和规格校验。
