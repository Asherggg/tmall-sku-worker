# 天猫运营工作台 v0.1.29

发布日期：2026-09-21

## 发布内容

v0.1.29 为历史商品增加显式销售渠道迁移流程。当天猫当前 bootstrap 中的 `channelOption` 为旧值 `5` 或空值时，SKU ID 重建与新增花型都会在任何销售属性预检或商品提交 POST 前停止，并将任务置为待人工复核。

- 旧值不会被白名单放行、忽略或自动映射。
- 运营只能在当前被阻断的单个任务上选择 `1`（纯电商）或 `2`（商场同款），并再次确认重试。
- Worker 在重试时重新读取 bootstrap，要求观察到的旧值未变化，且所选值在当前 `components.channelOption.props.dataSource` 中恰好出现一次。
- 当前值已变为合法 `1/2` 时，过期选择不能覆盖页面；候选缺失、重复或源值漂移都会继续零写入阻断。
- 环境变量、新建批次载荷、普通重试和兄弟任务不能提供或继承渠道选择。
- 恢复证据保留原始渠道值，并把人工选择单独记录为计划渠道；最终新鲜回读严格核对实际渠道。
- 全部 Excel 组合已存在时仍保持零 POST 完成，不会声称线上旧渠道已被修改。

v0.1.28 的 Windows Job Object、NSIS 精确路径清理、专属 Edge 脱离 Job、两路商品流水线、全局串行写锁、150 秒严格回读和未知写入禁止重试均保持不变。
