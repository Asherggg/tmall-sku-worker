# v0.1.21

## 国补纯接口改造

- 国补默认通过已登录专属 Edge Profile 的 `BrowserContext.request` 调用 MTop/OSS 接口，不再依赖页面按钮、抽屉、文件控件或导航。
- 使用当次 `_m_h5_tk` 会话前缀计算 MTop 签名；Cookie、签名、OSS Policy、临时 URL、上传 key 和完整请求体不写入仓库、任务状态或审计导出。
- 已验证并实现模板 `EXPORT`、`QUERY_PROGRESS`、模板下载、OSS 上传配置、文件 `IMPORT` 和商品列表回读契约。
- `IMPORT` 前保留现有外部写入状态持久化门禁；该请求遇到 token 失效、网络超时或未知响应时不自动重试。
- 提交后按商品 ID 回读，逐项确认新 SKU ID、69 码、国补品名和规格。任一字段不一致时进入 `needs_manual_review`。
- 页面流程保留为显式 fallback，可通过应用数据目录 `runtime-config.json` 设置 `TMALL_SUBSIDY_TRANSPORT` 为 `page`；默认值为 `api`，接口失败不会自动切换页面提交。
