# Tmall SKU Worker v0.1.24

## 纯 SKU ID 重建

- 用户只需输入商品 ID，并在专属 Edge 中完成淘宝卖家中心登录。
- 线上任务只执行：商品快照、临时规格提交、新 SKU ID 回读、原业务字段恢复提交、最终服务端回读。
- 唯一预期持久变化是 SKU ID。规格、价格、商家编码、条码、图片和其他业务字段从天猫原始快照恢复；库存采用平台实时值。
- 未知提交结果或最终字段不一致仍进入 `needs_manual_review`，已发出写入后不自动重试。

## 移除内容

- 不调用 OMS，也不提供 OMS 登录入口或 Worker API。
- 不查询外部商品资料，不补全条码、品名或规格。
- 不导出、填充、上传或提交国补模板。
- 安装资源不包含流程凭据、运行时配置文件、ExcelJS、MySQL 客户端或旧流程适配器。
