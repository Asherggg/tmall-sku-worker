# Tmall SKU Worker v0.1.7

## 变更摘要

v0.1.7 将线上重建契约升级为 `tmall-publish-v2`，从“页面状态 + 内部提交事件”的混合方式改为纯 HTTP 接口方式。Edge 在登录验证后只作为认证会话容器，任务执行不会修改或导航天猫页面。

## 纯接口流程

1. `GET /tmall/publish.htm?id=<itemId>` 读取完整服务端表单、全局提交字段和销售属性元数据。
2. `POST /tmall/asyncOpt.htm?optType=salePropValueChangeAsync` 预检临时或恢复后的规格组合。
3. `POST /tmall/submit.htm` 直接提交完整表单，不触发 `button-submit` 页面事件。
4. 通过有界 HTTP GET 轮询回读新 SKU ID 和最终业务字段，不刷新、不跳转页面。

## 安全边界

- Cookie 和 XSRF 只从专属 Edge 的内存登录态读取，不进入源代码、任务状态或审计导出。
- 提交仍执行两阶段快照、精确 ID、业务字段和渠道校验。
- 服务端 bootstrap 或接口契约无法解析时直接进入人工复核，不回退为浏览器页面操作。
- 未知写入结果不自动重试。
