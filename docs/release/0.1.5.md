# Tmall SKU Worker v0.1.5

## 版本定位

v0.1.5 修复 Windows 安装版启动时 Worker 资源目录解析不一致的问题，并保留 v0.1.4 的 GUI 子系统和快速回读能力。主程序和 Worker 都在安装后自动启动，用户不会看到 CMD/终端窗口。

## 主要变更

- 发布版使用 Windows GUI 子系统，不创建控制台窗口。
- Tauri host 同时解析资源目录父级和安装程序所在目录，确保 NSIS 安装版能找到 `worker/server.mjs` 与 `runtime/node.exe`。
- 快速服务端回读、完整页面回退、两阶段线上重建和人工复核规则保持不变。

## 验证范围

- `npm test`：37/37 通过。
- `npm run build`：通过。
- `cargo check --manifest-path src-tauri/Cargo.toml`：通过。
- `npm run tauri:build -- --bundles nsis`：待本次构建验证。
