# Tmall SKU Worker v0.1.22

## 修复

- 修复从 v0.1.21 或更早版本升级/换机后，三个站点登录成功但批量导入仍提示流程未配置的问题。
- 根因是登录态与运行时流程配置是两套独立状态，而旧安装包不会在新电脑上创建 Doris/国补的 `runtime-config.json`，也没有应用内配置入口。
- Worker `/health` 现在返回精确缺失项，只缺 Doris 或国补时不再笼统提示 OMS、Doris、SKU 重建和国补全部未完成。

## 流程配置

- 左侧新增“流程配置”页面，可填写商品资料服务地址、查询路径和访问令牌，并启用国补流程。
- 配置写入 `%APPDATA%\com.local.tmall-sku-worker\worker\runtime-config.json` 后原子替换并重启 Worker。
- 已保存的访问令牌不会回显给前端；留空保存会保留旧令牌。
- HTTPS 默认允许；内网 HTTP 必须显式开启“允许内网 HTTP”。
- 首次启动在目标配置缺失时，按顺序迁移显式 `TMALL_RUNTIME_CONFIG`、应用数据一级目录旧配置或受支持的旧环境变量。已有目标配置永不被覆盖。
- 安装包不包含 Doris 凭据或共享永久 Token；新电脑仍需要由获授权用户录入设备/用户令牌。
