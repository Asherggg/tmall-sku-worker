# Tmall SKU Worker v0.1.12

## 变更内容

- 批次预览只展示前 10 个商品。
- 超过 10 个商品时，预览列表固定高度并在列表内部滚动，避免右侧面板和整个窗口持续变长。
- 列表下方保留剩余商品数量提示，导入数据本身不受限制。
- 同步桌面 UI、Worker、Tauri、安装包和文档版本号到 `0.1.12`。
